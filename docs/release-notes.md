zotero-centers 1.0.2：一个安装包提供五项功能，适配 Zotero 10.0.x。

- **全局搜索**：搜索本机个人及群组文库的字段、笔记和批注，结果使用原生列表。
- **行内编辑**：直接单击列表中的短标题或其他（Extra）字段编辑，支持原生撤销。
- **同标题合并**：跨条目类型合并，右侧可一键处理当前重复条目列表，保留附件、笔记、分类与元数据归档。
- **文库与目录总数**：「我的文库」后显示整个文库总数，包含未分类文献；各目录累计所有层级子目录的文献总数。同一条记录多处归类只计一次，不含附件、笔记和回收站条目。
- **Index 首列**：从 1 开始按当前排序和筛选连续编号，展开的附件和笔记不占序号。

安装 XPI 即可独立使用；不依赖 Global Search、Inline Extra、Title Merge 或 Zoplicate。若旧版三个插件已安装，Centers 会自动停用它们；禁用 Centers 时恢复被它停用的旧插件。

从本地测试包升级的用户，请手动覆盖安装一次本发行版，以接入 GitHub 自动更新清单。

Windows / Zotero 10.0.8 独立文库验证：70 项集成检查、18 项核心测试及 5 项 SQLite 测试通过。macOS、Linux 尚未实测。

仅按标题合并，主条目字段优先、空字段补全。合并前元数据归档不含附件文件，也不是一键恢复包。完整使用与保留规则见 README。
