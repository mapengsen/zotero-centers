zotero-centers 1.1.0 新增可直接编辑的「笔记」列。

- 默认显示在「出版物」后面，每篇文献初始为空，单击空白单元格即可输入。
- Enter 或失焦保存，Shift+Enter 换行，Esc 取消，Tab / Shift+Tab 切换文献；支持中文输入法和原生撤销/重做。
- 首次保存非空内容时才创建原生子笔记，支持 Zotero 同步；短标题、其他字段及已有普通笔记各自独立。
- 保存冲突或失败时保留草稿。合并文献后保留两边笔记，列中合并显示；编辑后仍保留原子笔记副本。
- 禁用后重新启用仍能读取已保存内容；表头可调整笔记列位置或隐藏。

保留全局搜索、短标题/其他直接编辑、同标题一键批量合并、文库与所有子目录总数和 Index 首列。

适配 Zotero 10.0.x。通过 Windows / Zotero 10.0.8 的独立文库测试；macOS、Linux 尚未实测。完整保留规则与验证报告见 README 和 `docs/validation-1.1.0.json`。

可在 Zotero 插件管理器检查更新，或下载本页 XPI 覆盖安装。
