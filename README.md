# zotero-centers

一个安装包，包含文献批量添加与元数据更新、全局搜索、短标题/其他/笔记直接编辑、同标题合并、文库与目录文献数量和首列 Index。支持 Zotero **10.0.x**。

## 安装

1. 从 [GitHub Releases](https://github.com/mapengsen/zotero-centers/releases/latest) 下载 XPI，或使用本地构建的 XPI，在 Zotero 中打开「工具 → 插件」。
2. 点击齿轮，选择「从文件安装插件」，打开下载的 XPI。已安装 Centers 的用户直接覆盖安装，沿用相同插件 ID。
3. 安装后出现顶部全局搜索框、左侧文库/目录数量、文献列表首列 Index，以及「出版物」后面的「笔记」列；点击「重复条目」可使用右侧同标题合并入口。

只安装这一个插件即可。若之前安装了 Global Search、Inline Extra 或 Title Merge，Centers 会自动停用这三个旧插件，避免重复加载；旧插件保留在插件管理器中。禁用或卸载 Centers 时，会重新启用被它停用的旧插件，原本已经停用的插件保持原状态。

GitHub 正式发行版提供自动更新清单，可通过 Zotero 插件管理器检查更新。之前安装本地测试包的用户，请手动覆盖安装一次 GitHub 发行版，以接入正式更新地址。

## 功能

### 批量添加与更新元数据

选择目标分类，点击魔杖旁边的「批量添加」，粘贴 DOI、DOI 链接、有 DOI 对应记录的 PMID、arXiv ID、标题或参考文献，每行一条。点击「查询并预览」，为标题搜索选定候选文献，再勾选要写入的结果。同一文库中已有的 DOI 会提示并跳过。

在「批量添加」里点击「从文件导入…」，即可使用 Zotero 原生导入向导读取 BibTeX、RIS、Zotero RDF 等格式。文件导入的位置、新建分类和附件处理按 Zotero 向导的选项执行。

选中一条或多条文献，右键选择「查询并更新元数据…」。选中已有父条目的附件时会更新父条目。独立 PDF 可以手动填入 DOI 或标题，确认后创建父条目并保留原 PDF。现有文献原位更新，保留条目键、附件、笔记和分类。每条更新前在 Zotero 数据目录的 `centers-metadata-backups/` 保存原始记录，已保存的元数据修改可通过 Zotero 撤销。

查询会把标识符或标题发送给 Crossref、Europe PMC、DataCite、OpenAlex、Semantic Scholar 或 DBLP。预览显示每个字段的候选值和来源，也可以保留当前值。默认优先推荐有卷期或纸本证据的日期，可以切换到「在线发表优先」。如果来源明确给出预印本和出版版的 DOI 关系，可核对并选择出版版。通过「查询来源」中的 DOI 链接可打开出版页面核对。

期刊文章的「出版物」和「期刊简称」分别核对。简称优先采用 MEDLINE 提供的值，来源提供其他简称时也可在预览选择。

如果登记的文章编号与 DOI 后缀相同且像出版商内部编号，优先推荐其他来源提供的页码或文章编号；只有登记值时，默认留空或保留当前值，等待核对。

### 全局文献搜索

顶部输入内容，停顿 250 毫秒自动搜索；Enter 立即搜索，`Ctrl+Alt+F` 聚焦。搜索所有已同步到本机的个人和群组文库，包括文献字段、作者、标签、分类、其他、子笔记和批注。结果显示在原生文献列表，保留排序、右键菜单和右侧详情；右上角原生搜索框可继续缩小结果范围。Esc 或 × 恢复之前的目录和搜索条件，点击目录也会退出全局搜索。

按整个输入内容的子串匹配，忽略大小写、统一全半角和连续空白。子笔记或批注命中后显示所属文献。不搜索 PDF/EPUB 正文，不做 OCR；排除回收站和订阅源。

### 短标题、其他与笔记直接编辑

单击列表的「短标题」或「其他」单元格即可编辑，包括空值。若没有这两列，右键表头勾选。Enter 或失焦保存，Esc 取消，Tab / Shift+Tab 保存并移至下一篇 / 上一篇的同一字段；F2 编辑所选文献的其他。其他支持 Shift+Enter 换行，中文输入法确认不会提前提交。使用 Zotero 原生撤销 / 重做恢复字段修改。

分别写入原生 `shortTitle` 和 `extra` 字段，支持正常同步。附件、笔记、回收站、只读文库和订阅条目不提供此入口。

**笔记列**默认显示在「出版物」后面，每篇文献初始为空，单击空白单元格即可输入。Enter 或失焦保存，Shift+Enter 换行，Esc 取消，Tab / Shift+Tab 保存并移至下一篇 / 上一篇的笔记。支持中文输入法及原生撤销/重做。表头菜单可隐藏此列，拖动表头可调整位置，列设置会保留。

首次保存非空内容时，创建该文献的一条原生子笔记；打开空白编辑框再取消不会生成笔记。它使用专用自动标签 `zotero-centers-note` 识别，与短标题、其他字段及已有普通子笔记分开保存，随 Zotero 正常同步。禁用插件后，内容仍作为原生子笔记保留。普通笔记不会自动填入新列。

同标题合并会保留各条文献的笔记，并以空行分隔显示在笔记列。编辑合并后的内容时，原笔记副本仍保留为普通子笔记。保存前发现其他地方已修改笔记时，会保留当前草稿并提示冲突。

### 同标题合并

点击左侧「重复条目」，右侧点击「一键合并当前列表全部同标题文献」，自动扫描并依次处理当前筛选列表中的全部匹配组，无需逐个点击。保留单组合并和预览入口，也可从「工具 → 同标题合并…」选择整个文库。操作显示进度，可在当前组合并完成后停止。

只按标题匹配，忽略英文大小写及多余空白；保留标点，不做模糊匹配。作者、DOI、年份和条目类型不同也会合并。不同文库分别分组。

主条目优先级：期刊论文 > 会议论文 > 预印本 > 其他。同类型按元数据完整度、最早添加时间选择。主条目已有字段和作者优先，空字段使用其他记录补全；并非按最近修改时间覆盖全部字段。

使用 Zotero 原生合并处理附件、批注、子笔记、标签、分类和引用替代关系。原始字段、类型及冲突值写入主条目的「合并前元数据快照」子笔记，并归档到 Zotero 数据目录下的 `title-merge-archives/<批次>/`。归档为元数据，不包含附件文件，也不提供一键恢复文库。

不依赖 Zoplicate。已安装时，合并期间临时停用正在启用的 Zoplicate，完成后恢复。

### 目录文献数量

「我的文库」后显示整个个人文库的文献总数，包括未分类文献。同一条 Zotero 记录只计一次，不含附件、笔记、订阅源和回收站条目；各群组文库显示各自独立的总数。

每个普通目录后显示 `(数量)`，包括空目录 `(0)`，支持个人与群组文库。统计**当前目录及所有层级子目录的文献总数**，不含附件、独立笔记、批注、订阅源和回收站条目，也不累计已删除子目录的内容。同一条 Zotero 记录同时属于父目录或多个子目录时，在该父目录总数中只计一次；不同记录即使标题相同仍分别计数。

新增、移动、删除、恢复和合并文献后自动更新；移动整个子目录时，也会重新统计新旧父目录及其祖先目录。搜索或标签筛选不会改变目录总数。数量只是界面标记，不修改目录名称或文献字段。

### 首列 Index

文献列表最前面增加 **Index**，按当前可见文献顺序显示 `1、2、3……`，数字在前、文献类型图标在后，附件展开箭头保留在左侧。排序、搜索和切换目录后重新编号；全局搜索结果同样适用。展开的附件、子笔记、独立笔记和文库分组标题不占编号。点击 Index 表头不改变文献排序。

Index 是当前视图的序号，不写入文献字段，也不是永久文献编号。可通过原生表头列菜单隐藏，通过拖动表头调整位置。

## 开发与验证

需要 Node.js 22+ 和 Python 3.9+，不需要 npm 依赖。

```powershell
npm run check
npm test
npm run build
```

构建输出在 `dist/`，内容只有正式插件和许可证。固定文件顺序与时间戳，可重复构建。三个原项目目录保持独立；合并版使用自己的插件 ID，运行时不依赖另外三个 XPI。

真实 Zotero 测试：`python scripts/test-zotero.py` 在 `.tools/runs/` 下创建独立配置与测试文库，再使用 `zotero.exe -no-remote -profile <生成的 profile 路径> -purgecaches -ZoteroDebugText` 启动。测试脚本中的数据目录检查会阻止它在正常文库里运行。完整报告写入 `test-results/`，正式 XPI 不带测试入口。

迁移测试使用 `tests/legacy/` 中冻结的三个旧版安装包，只作测试夹具，不包含在正式 XPI 中；Zoplicate 共存测试需要另外提供 `.cache/zoplicate.xpi`。测试在 Windows 隐藏窗口中验证原生 DOM、鼠标事件与数据 API，跳过回收站树在隐藏窗口中的视觉刷新等待；生产插件不替换数据层或原生合并事务。其他操作系统尚未实测。

源码来源：Global Search 1.1.0、Inline Extra 1.1.0、Title Merge 1.2.0，新增目录计数与 Index 模块。按 MIT 许可证分发，保留 Inline Extra 原始许可证。

1.0.1 将目录数量改为累计所有层级子目录的文献总数，同一条目在父目录及多个子目录中只计一次，移除或移动整个子目录后自动更新祖先总数。已在 Zotero 10.0.8 通过 69 项集成检查、18 项核心测试和 4 项 SQLite 测试；发布验证记录见 [docs/validation-1.0.1.json](docs/validation-1.0.1.json)。
